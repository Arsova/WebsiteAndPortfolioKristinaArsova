# Kristina Arsova — Portfolio Website

A lightweight static website for GitHub Pages.

## Pages

- `index.html` — Home, services overview, selected work, newsletter
- `about.html` — Professional introduction, mission, vision, way of working
- `portfolio.html` — Personal projects, collaborations, current projects
- `services.html` — Training, workshops, consultancy, freelance services, contact
- `journal.html` — Blog posts and newsletter signup

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `kristina-portfolio`.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will usually be available at:
   `https://YOUR_GITHUB_USERNAME.github.io/kristina-portfolio/`

## Before publishing

- Replace `hello@example.com` with Kristina’s real email address.
- Replace placeholder project cards with real titles, descriptions, and images.
- Connect the newsletter form to a provider such as Mailchimp, Buttondown, Substack, or Formspree.
- Optionally add a custom domain in GitHub Pages settings.
